# 1.1.0 · 七灯余响实现与验收

> 历史记录：用户已否定该样板的玩法方向。自 1.1.1 起，主体验统一延续第一版；本页的样板范围、后续顺序与测试结果仅描述 1.1.0，不代表现行版本。当前要求见 [GAMEPLAY-DIRECTION.md](GAMEPLAY-DIRECTION.md)。

基线：远程 main `85c5994d8857379cc8adc20e5eb9e705533b2b71`（1.0.5）。规格：[第二版完整设定](../暮边镇_第二版_七灯余响_完整设定.md)。本次对应第 10.2 节阶段 1；完整续章并未交付。实现仍是 JavaScript Canvas + Java Android 宿主，非 C++。

## 已可游玩的内容

- 一处俯视二维训练庭，两块实体掩体，四种不同运动靶；自由走位与移动射击互不锁定。
- 守灯人：6 生命、6 护盾、120 能量；四秒未受伤后逐点回盾；两次闪步储量逐次恢复；灯环减伤并清普通弹。
- 手枪 P01、散弹 S01、短剑 M01、线灯杖 W01；免费初始武器、独立冷却、共享能量、两槽切换。零能量双耗能武器可以在暂停菜单换免费应急手枪。
- 左摇杆和右攻击区同时触控；攻击键点击一发、按住连发、拖动手动瞄准。辅助瞄准检查遮挡与射程，手动输入短暂优先。
- 三类敌人：雾噬鼠、裂爪犬、空壳弩手。两波试炼含出生预警、近战前摇、犬冲锋、弩手扇形三弹、绕掩体寻路。
- 子弹扫掠检测按墙和目标的距离顺序处理，避免穿墙；同一散弹包对同一敌人最多结算一次；短剑只在有效帧的前方扇形清弹。
- 分离身体、武器与投射物绘制；命中闪光、材质音、四类武器发声、关闭震屏、30/60 绘制档。程序占位造型不代表正式像素图集。
- 暂停、设置、键位重绑、军械台、药剂、试炼结果、导入导出与完整房内快照恢复。训练不发永久货币，铜筹仅属于本次试炼。
- 独立序章入口保留 1.0.5 的流程、剧情与存档。重用原有 Android 离线资源、诊断、签名、文件传输；双入口分别握手。

## 存档边界

原键 `duskbound.save.v1` 保持原样。首次迁移先复制原始主档与备份至 `.before-v2` 键；已有不同备份时使用带校验摘要的键保留，读回确认后才允许写 `duskbound.save.v2`。原始字节损坏或备份写入失败时阻止自动覆盖。

新档 schemaVersion 为 2。保留旧结局、阶段、任务标记、日志、旧币、灰铁、苦叶、药膏；强化变为修复纪念及 6 灰铁，超过两瓶的药进入镇仓。旧版途中状态回到安全训练庭，不把旧敌人导入新战斗。迁移完成后两个存档独立，后续序章游玩不会重复迁移以增加财富。

房内玩家、敌人、子弹、计时器和两波奖励账本一起保存；继续是「继续本房」。每波奖励和已领取标记同一快照提交。写入采用临时记录、有效旧备份、主档顺序；损坏新主档恢复前另存原始损坏字节。新旧存档需要在各自页面分别导出。

## 独立准备与下一步

`web/src/v2/data.js` 存放武器、职业、样板敌人/房间初值；`roadmap.js` 准备三地区、27 模板、四首领、十二遗物、八事件、八支线和三结局条目。它们是制作清单，不是已完成行为。正式美术清单见 [ART-V2-PRODUCTION.md](ART-V2-PRODUCTION.md)。

真人先在训练庭分别使用四武器，验证一发/连发、走射、拖瞄、切枪、贴墙闪步、短剑清弹和两波试炼，再记录：机型、Android/WebView、屏幕刷新率、30/60 档、操作不响应/误触次数、战斗感受。至少补足 OPPO Find X8 与另一档安卓设备的安装覆盖、文件导入导出和切后台测试，再进入美术样板与灰风区域闭环。
