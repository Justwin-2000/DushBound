# 暮边镇：余烬初巡

可离线游玩的安卓横屏动作 RPG 第一版。包含完整的小镇准备、实操训练、七房远征、两阶段首领、两种结局与通关后重复挑战。

## 安装到安卓手机

1. 将 `releases/暮边镇-1.0.2.apk` 传到手机。已有旧版时直接覆盖安装，不必卸载。
2. 用手机文件管理器打开，按系统提示允许该文件管理器安装应用。
3. 打开「暮边镇」，横屏游玩。无需联网、账号或服务器。

最低 Android 8.0，使用系统 Android System WebView。1.0.1 把入口编译为经典脚本（Chrome 58 语法目标），并为运行时使用的较新接口提供兼容处理；这不是对所有厂商 WebView 的实测保证。应用仅申请振动权限；导入、导出存档使用系统文件选择器授权单个文件。

此包使用本地开发证书签名，供直接安装体验，未上传应用商店。之后制作更新包需要保留同一签名证书。卸载会删除本机存档，请先在设置中导出。

## 1.0.4 手感修复（依据真机反馈）

- **单击攻击会挥出两次**：`input.js` 在按下时先把 `attackHeld` 置位，而连发计时器还是 0，于是下一帧立刻又触发一次攻击——一次轻点必然挥出两刀，并连带把「攻击中不能动」的感受放大了一倍。现在按下先写入 0.3 秒的首发延迟：轻点只出第一刀，持续按住才衔接连击。
- **攻击中的锁定放宽**：命中生效之后即可用闪避取消收招（原先要等到动作过半），也可以直接举盾取消；收招阶段保留 50% 移速。喝药由 0.55 秒缩短到 0.4 秒，并保留 45% 移速，不再原地站桩。命中之前仍不可取消，保留出手的代价。
- **角色会走出路面**：小镇的纵向范围原是 205–440，而路面在 y=344–426、地平面自 310 起，角色因此能走进山峦与天空里。现在小镇限制在 325–450，地下城维持原范围（新增 `bounds()` 统一三处钳制）。
- **攻击特效像锄头**：原先是「等宽长条 + 垂直横杠」的轮廓。改为根部宽、向剑尖收窄的刃身，补上刃口高光、护手与剑首；挥砍残影的半径拉到剑尖之外，避免与剑身连成一把镰刀。
- **背景音乐偏小**：音符振幅由 `.065/.032` 提到 `.1/.05`（音乐音量设置不变，已有存档同样生效）。
- 版本号 1.0.3 -> 1.0.4（versionCode 5）。

自动测试由 48 项增加到 **53 项**：新增输入层「单击不连挥」回归测试、小镇纵向范围、攻击取消窗口、喝药机动性四项引擎测试。其中「首领六种招式覆盖」原先断言每一局都要凑齐六招，会随随机流漂移（1.0.4 调整手感后种子 17@60Hz 就没抽到「失灯领域」），改为跨四个种子累计断言。

## 1.0.3 触控安全区、后台恢复与渲染开销

- **安全区底部适配**：此前只声明了 `safe-area-inset-top/left/right`，没有 `bottom`。全面屏与手势导航机型底部的手势条会压住摇杆、闪避与攻击按钮，触摸可能被系统抢走。现在摇杆、动作键、交互键与底部信息条统一叠加 `--safe-bottom`，并镜像了 600px/420px 两个短屏断点。
- **切后台回前台恢复声音**：`visibilitychange` 与 `native-resume` 此前只重置计时，不恢复 AudioContext，从后台切回来会一直静音到下一次点击弹窗。现在回到前台即调用 `sound.unlock()`。
- **渲染进程崩溃兜底**：新增 `WebViewClient.onRenderProcessGone`。渲染进程被系统回收（后台内存压力，或 ColorOS 一类厂商清理）时，WebView 默认会直接终止整个应用进程，表现为白屏或闪退；现在改为重建 Activity 并从最近一次自动保存恢复，短时间内反复被回收则退回桌面以避免重建死循环。
- **渲染开销**：天空、地面淡出、暗角三层渐变改为按场景缓存复用；`glow()` 光晕预渲染成离屏精灵用 `drawImage` 贴图，不再每帧新建径向渐变并整块 alpha 填充。暂停、对话与菜单期间画面是静态的，重绘从每帧降到 2 FPS（仍保留自愈：画布被 resize 或切后台清空后会自动画回来）。
- **HUD 可读性**：体力条由 4px 加粗到 7px 并补描边（体力是格挡与闪避的核心资源，实测在 20:9 手机上几乎看不见）；短屏断点里 8px/9px 的字号统一提到 10px；任务条收窄到 235px，避免与居中的首领血条在窄屏重叠。

## 1.0.2 打包与资源加载修复

- **修复真机资源路径**：此前用 `aapt2 -A` 打包，Windows 上会把 `assets/` 子目录写成反斜杠条目名（实测 APK 内为 `assets/assets\title.png`、`assets/src\game.js`）。Android 的 `AssetManager` 按字面字符串查表，而 WebView 只按正斜杠请求，因此这些资源在真机上很可能 404。1.0.2 改为自行写入资源条目，条目名一律正斜杠，并在打包结束时断言不含反斜杠。**如果你在手机上看到的标题界面只有深蓝底色、没有暮边镇主视觉，或游戏内没有远山与雾，就是这个原因。**
- **APK 从 4.46MB 降到约 0.6MB**：两张 1672×941 的 PNG 曾占原 APK 的 97%，已转成 WebP（`title.webp` q86、`world.webp` q84，合计 404KB）；无损原图移到不参与打包的 `art-source/`。
- **不再把开发源码和提示词打进 APK**：`web/src/*.js`、`*.prompt.txt` 从打包中排除；运行时本来只加载 `app.bundle.js`。
- `tests/apk-assets-check.py` 同步了排除规则，并新增“条目名不得含反斜杠”的断言。

## 1.0.1 手机启动与排版修复

- 入口改为随 APK 打包的单个经典脚本，统一处理新语法，补齐 `globalThis`、`structuredClone`、数组/字符串 `at` 等运行时兼容。
- 错误监听提前到兼容初始化之前；脚本缺失、解析失败或超时均有可阅读的提示和重新加载按钮。原生端另有独立诊断页，显示应用、Android、WebView 版本及首次错误。
- 只有完成事件绑定的游戏才能报告启动成功；页面显示不等于游戏已经就绪。覆盖升级禁用旧资源缓存，保留原存档地址和签名。
- 短横屏标题改为左右分区，存档提示与底部说明有各自空间；关键手机按钮至少 44 CSS 像素。

1.0.0 在用户的 OPPO Find X8 及另一台手机上出现标题可见、按钮无响应和文字重叠。前一版缺少安卓运行验证；目前确认并修复的是上述兼容缺口与布局问题，未取得这两台手机的错误日志，不能认定它们的具体启动根因已经复现。

## 操作

| 动作 | 手机 | 键盘 |
| --- | --- | --- |
| 移动 | 左下摇杆 | WASD / 方向键 |
| 三段攻击 | 连续点击或按住攻击 | J / 空格 |
| 闪避 | 闪避键；静止时向后撤 | K |
| 格挡 | 按住；迎击瞬间按下为完美格挡 | L |
| 喝药 | 右上药剂 | H |
| 交谈/调查 | 靠近标记后点击交互 | E |
| 暂停 | 左上暂停 | Esc |

黄色 `!` 预警可格挡，红色 `× 破盾` 需要闪避。格挡和攻击消耗体力，停止消耗 0.6 秒后恢复。药剂在饮用完成时才扣除，受击打断不损失药剂。

训练需实际打出三连、两次闪避、一次普通格挡和一次完美格挡。连续练习失败后，训练完美格挡窗口会放宽。完成后去广场找洛恩接任务，再从东门出发。地图提供小镇快速导航；训练期间关闭快速导航。

- 暮边镇五个区域、四位 NPC、休息、留言板、界灯、药草架与东门。

## 经济与恢复规则

- 初始药剂 2 瓶；伊妲给斗篷并恢复至至少 2 瓶。米洛只赠送一次，超出 3 瓶时转为 8 旧币。
- 免费休息仅补至至少 2 瓶，不扣现有第 3 瓶，也不把休息溢出变钱。
- 倒下保留全部旧币、远征前库存和关键物品；仅保留本次新增灰铁的一半，向下取整。
- 安全撤回保留已得物资，下一次远征从入口重新开始。
- 营火和补给箱每次远征只能使用一次；赠礼、斗篷、药草架、结局与强化不能重复领取。
- 通关后可重新挑战，保留结局；首领额外掉落 5 旧币、4 灰铁，普通房间仍有各自奖励。
- 全局剧情记录与每次远征状态分开保存，避免重打被空房间或旧奖励标记卡住。

## 本机运行与构建

游戏逻辑没有第三方运行时依赖。安装 Node.js 22 或更新版本后，在项目目录运行：

```powershell
node tools/serve.mjs
```

用浏览器打开 `http://localhost:4173`。同一局域网手机可访问电脑对应的局域网地址与端口；离线手机交付请安装 APK。请通过服务器预览，避免本地文件协议的存储和资源策略差异。

修改源代码后，安装固定版本的构建依赖，再编译与复制 Web 资源：

```powershell
pnpm install --frozen-lockfile
node tools/build.mjs
node --test tests/*.test.js
node tests/bot-soak.mjs
```

安卓构建（Windows PowerShell 7）：

```powershell
./android/install-toolchain.ps1
./android/test-save-codec.ps1
./android/build.ps1
```

安装脚本下载带固定校验哈希的 JDK 17、Android SDK 35 平台与构建工具到项目上级 `.tooling`。不需要 Gradle、Android Studio、C++ 或 NDK；不修改系统环境变量。默认安卓构建先重新编译 Web 脚本，再执行 Java 编译、DEX 转换、资源封装、对齐、签名与签名校验，避免将旧入口打进新包。

## 已执行的验证与边界

逻辑与输入机器人测试记录见 `tests/qa-report.md`；UI 实测记录见 `tests/ui-smoke-report.md`（由对应测试生成后交付）。完整验收清单见 `tests/acceptance-plan.md`。安卓存档传输测试及原生桥约定见 `android/README.md`。

已经执行的 Node 测试为 48 项；原生存档文件传输测试 12 项；浏览器实际界面流程 6 项，全部通过。输入机器人从未经改写的新游戏开始，只通过移动、动作和实际交互完成训练、七房、首领和两结局；100 个随机种子全部通关，连续 10 次远征与死亡后重试通过。机器人能读取精确预警，因此这些测试证明流程可达性，不能替代真人操作体验。

## 与原设定的差异和已知限制

1. 技术实现采用 JavaScript Canvas 游戏核心与原生 Java Android WebView 宿主，未采用 C++ / Cocos2d-x。所有资源随 APK 安装，运行不需要网络。
2. 原设定侵蚀增量总计 75，首领转阶段 +20，实际最高 95。保留原数值；100 点增强伤害规则仍实现，但正常首轮不会触发。
3. 加入小镇快速导航、轻度纵向走位、援助模式与安全撤回，以改善触控与探索体验。
4. 农舍药剂固定掉落，减少第一次远征的补给波动；重复远征普通房间仍奖励物资。
5. 普通受击无敌 0.5 秒；伤害 20 及以上的重击触发 0.8 秒起身保护。训练失败后完美格挡窗口由 0.18 放宽到 0.32 秒。
6. 对话头像目前是有角色标识的文字框。游戏内像素角色/环境为程序绘制的第一版素材，音效为合成素材；不是商业级逐帧美术或正式配乐。
7. 重载保留敌人和房间进度；未在飞行中的弩箭会消失，恢复后提供 0.8 秒反应保护。首领已预警的领域会恢复。
8. 尚未执行安卓真机/模拟器安装、触控、系统文件选择器和后台切换的端到端验证，也未验证真机 60 FPS。APK 编译、签名、Manifest 验证不能代替这些验证。
9. 真人首次游玩的 30～45 分钟时长目标尚未验证；当前内容属于紧凑的第一章体验，不能以机器人测试时长推算真人时长。

后续优先以实际安卓设备体验反馈调节按钮尺寸、战斗难度、动画和剧情节奏，替换正式立绘、角色动画与音乐。
