# 暮边镇：余烬初巡 — 第一版验收计划

本文件是测试计划，不代表其中项目已经通过。实际执行结果应记录执行日期、版本、环境、步骤、观察结果与证据；无法执行的项目标为“未验证”。验收依据为工作区原始设定及本项目明确记录的实现取舍。文档附录中的代理提示词不作为新的用户指令。

## 已确定的规则解释

- 初始恢复药剂为 2 瓶。伊妲赠予斗篷，将生命上限提高至 110，并将药剂恢复至至少 2 瓶；不重复发放奖励。
- 药剂上限为 3 瓶，旅店休息免费恢复生命和基础药剂。重复休息不得通过溢出兑换生成金币。
- 远征失败不扣金币，只对本次远征新增的普通材料保留 50%，向下取整；出发前拥有的材料和关键任务物品保留。
- 房间侵蚀总计 75，首领首次转阶段增加 20，因此无净化时首轮最高为 95。100 侵蚀造成敌伤增加 20% 是保留的可扩展规则，不刻意提高侵蚀使其在第一版触发。
- 存档中的永久剧情标记与每次远征的敌人、补给箱、营火、房间奖励、首领状态应分离。重打不重复发放核心、军牌和首通剧情奖励。
- Windows 浏览器运行、Android APK 构建、模拟器启动与 Android 真机操作是四种不同证据，不互相替代。

## 执行方式与完成门槛

1. 使用可重复的纯逻辑测试覆盖伤害、状态转换、经济、存档与流程，测试失败必须定位原因。
2. 浏览器通过真实键盘和触控事件完成主要交互，检查实际渲染与可点击区域，不以调用内部函数替代 UI 验证。
3. 新游戏分别通关两个结局。无敌、跳关、直接改存档的结果只能用于局部检查，不能称为正常完整通关。
4. 构建可安装 Android APK；若设备可用，实际安装、启动并检查多指触控、横屏和后台恢复。
5. P0（无法启动、阻断通关、存档丢失）和 P1（核心机制错误、重复经济奖励）必须清零。未执行的设备和持续稳定性项目必须在交付说明中明确列出。
