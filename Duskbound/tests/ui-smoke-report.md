# 界面实测记录

2026-09-09，Windows 本机 Microsoft Edge headless，通过 Playwright 操作本地游戏。对应脚本 `ui-smoke.mjs`，详细机器结果与截图在 `output/`。

## 已通过

| 场景 | 操作与结果 |
| --- | --- |
| 新游戏与伊妲 | 实际点击标题、推进初醒对白、按键移动到伊妲、交互领取斗篷；生命变为 110，任务推进 |
| 实际训练 | 地图到铁匠铺、对话开始训练；真实按键三连、两次闪避、普通和完美格挡；训练完成 |
| 菜单与继续 | 暂停、背包、修改音量/震屏/援助/帧率；刷新页面后继续，任务、库存、设置均恢复 |
| 安卓布局模拟 | 844 × 390、touch+mobile 模式；真实 CDP 两个触点同时摇杆移动与攻击，药剂/闪避/格挡可点，菜单可滚动 |
| 平板布局 | 1024 × 768，标题、触控区与菜单均在视口内 |
| 后台对白恢复 | 发送原生桥公开的 native-pause / native-resume 事件；明确关闭暂停菜单、完成对白后可继续移动 |

六项全部通过。监听到的 pageerror、console.error、HTTP 失败与资源请求失败均为 **0**。

## 本轮修复

- 手机横屏下暂停、地图、背包、药剂等关键按钮从 35px 扩大至至少 44px；任务按钮也至少 44px。
- 提示最多显示一条，移到操作区上方，避免覆盖交互键和底部资源。
- 新玩家优先显示高亮的「开始新旅程」；有存档后优先「继续旅程」。
- 原生后台事件发生在对白中时，会显示明确的暂停菜单，恢复后可以继续。

截图用于视觉检查，不是安卓设备截图。触控模拟、桌面浏览器和公开生命周期事件测试均不能代替安卓真机的安装、音频、SAF 文件选择器、设备系统回调或性能测试。

## 复现

先运行 `node tools/serve.mjs`，再运行 `node tests/ui-smoke.mjs`。脚本当前检测本机的 Playwright 与 Edge 路径；换机器可用 `PLAYWRIGHT_MODULE` 和 `BROWSER_PATH` 环境变量指定相应安装位置。
