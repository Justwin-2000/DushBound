# 暮边镇统一玩法方向

确认日期：2026-09-10。依据：用户明确反馈第一版玩法不错，第二版割裂，房间战斗枯燥，要求延续第一版。本文取代第二版完整设定中与之冲突的玩法与制作顺序要求；原设定保留作为历史设计资料。

## 核心体验

小镇是旅程的起点与归处。玩家通过交谈、调查、准备与远征推进人物关系和故事；战斗是旅途中的紧张段落。沿用第一版的横向场景表现与地面纵深移动、近战连击、体力管理、闪避、普通格挡和完美格挡，以及已经改善的挥剑节奏、取消收招和音效。

入口统一为「继续旅程 / 开始新旅程」。不要求玩家选择新旧版，也不在章节间突然换成双摇杆射击和另一套养成经济。章节变化以人物、环境、敌人行为和故事推动，保留熟悉的操控。

## 后续内容设计准则

- 先确定一个地点为何值得探索，再安排遭遇。路径、环境线索、人物目标和返程变化共同构成内容。
- 节奏交替：可观察的行进、短互动、调查、伏击、避战选择、特殊目标、高潮战斗与回镇反馈；不要求每处地点清空敌人才能前进。
- 新战斗主要增加局势变化：地形利用、敌人搭配、护送/救援/中断仪式等目标、清楚的预警和合理退路。不同目标是后续设计方向，尚未实现。
- 精英和首领服务于地点与人物故事，通过招式和行为形成区别；不靠堆血量或增加无预警伤害延长时间。
- 每次战斗后尽量有具体变化：打开路线、救下角色、获得线索、改变小镇对白，避免只有重复掉钱。
- 第二版的灰风、港口、雨幕、人物与七灯故事可以继续发展，但按上述玩法重新编排。暂停以 27 个封闭战斗房、24 枪、四射击职业为数量目标的扩张。

## 1.1.1 实际改动

1. 主入口恢复完整第一版流程，直接沿用原本的角色、战斗、剧情与地图。
2. 移除玩家可见的新旧版分流、试炼庭入口与第二套操作；原序章地址自动转到统一入口。
3. 使用既有 `duskbound.save.v1` 剧情存档，不回退存档、不换算战斗状态。1.1.0 保留的该存档可继续读取；样板记录和备份留在本机，不发额外财产。
4. 从正式构建中撤下射击样板脚本及样式；试验源码与 Git 历史保留供技术参考。
5. 版本号升级到 1.1.1（Android versionCode 8），同步 README 与协作要求。

本版是玩法方向和入口的统一，不宣称已经改造第一版现有七房远征、制作开放世界或完成续章。下一轮内容改造应先选择一段现有远征，将探索、事件和场景变化实际做进其中，再基于试玩扩展。

## 存档与验证边界

已有 1.0.x 或在 1.1.0 回看序章的玩家，直接继续剧情存档。只有 1.1.0 试炼记录的玩家从「开始新旅程」进入第一章；训练未产生永久奖励，不转换成旧币、强化或通关记录。原样板数据不删除，但不再提供活跃游戏入口。

升级测试覆盖两种旧结局及资产保持、仅有样板记录时开新剧情、旧地址重定向、样板与备份字节不变，并回归启动、触控和既有逻辑。浏览器与 JVM 测试不能代替安卓设备实测；设备体验的未验证部分应在 README 中如实标注。
