# 暮边镇：余烬初巡

**当前版本：1.1.2 · 统一玩法**

一款离线安卓横屏动作 RPG。提起界灯，在小镇与灰风原野之间往返，通过交谈、探索、近战与抉择推进旅程。

根据玩家反馈，玩法统一延续第一版：保留近战连击、体力、闪避与格挡，以及小镇探索和剧情远征。1.1.0 的独立射击训练庭已退出主体验。后续章节沿用熟悉的操控，以人物、场景和事件丰富冒险。完整方向见 [玩法设计](Duskbound/GAMEPLAY-DIRECTION.md)。

## 1.1.2 更新（存档安全）

- **存档版本迁移机制**：此前 `saveVersion` 与当前版本不一致的存档会被直接判为损坏，并把保存永久锁死——一旦以后提升存档版本号，所有老存档都会卡在「无法保存」上。现在改为逐级迁移：升版本时在 `SAVE_MIGRATIONS` 补一条对应步骤即可；缺少步骤时明确拒绝，而不是静默接受。
- **更新版本的存档不再被误判为损坏**：回退安装时提示改为「存档来自更新的游戏版本，已原样保留」，并且**不覆盖**原始字节。
- **崩溃后可用残留记录恢复**：写入中断留下的 `.pending` 现在会作为主档与备份都不可用时的最后一条恢复路径；**首次保存也会写备份**（此前首存不写备份，主档一坏就无从回退）。
- **导出存档回读校验**：系统文件选择器的目标文件做不了「临时文件 + 改名」，因此改为写入后逐字节回读比对。拷贝被中断或截断时会如实报错，而不是让玩家拿着一份不完整的备份却以为导出成功。
- **美术制作合同按现方向重写**：`ART-V2-PRODUCTION.md` 原先是针对 1.1.0 射击样板的四向角色、枪口锚点与职业体态规格，现改为侧视近战规格。
- 版本号 1.1.1 -> 1.1.2（versionCode 9）。

**存档兼容性**：本次不改变存档格式，`duskbound.save.v1` 原样读取，老存档无需迁移即可继续。迁移机制是为将来升版准备的。

## 1.1.1 更新

- 启动直接进入「继续旅程 / 开始新旅程」，取消新旧版分流。
- 恢复第一版完整流程：小镇准备、实操训练、七房远征、两阶段首领、两个结局与重复挑战。
- 保留第一版已有的挥剑节奏、音效、攻击取消与移动适配改进。
- 原剧情存档直接继续；1.1.0 试验数据和原始备份留在本机，不转换为剧情货币或强化。
- 原序章链接自动进入统一主菜单，正式构建仅加载一套游戏入口。
- 第二版的角色、地区和故事作为后续素材；与当前方向冲突的房间射击、双武器能量护盾与职业设计停止作为制作目标。

本版完成入口与玩法方向统一，尚未改造现有七房远征的内容结构，也未完成新地区或续章。后续重点是让探索、事件与战斗交替发生，减少重复清房。

## 安卓安装

最低 Android 8.0，使用系统 Android System WebView，横屏运行。安装后无需联网、账号或服务器。

1. 将交付的 `暮边镇-1.1.2.apk` 传到手机，在文件管理器中打开。
2. 按系统提示允许当前来源安装。已有同签名版本时直接覆盖安装。
3. 打开「暮边镇」，确认首页显示 `v1.1.2`，继续旅程或开始新旅程。

本地安装包位于 `Duskbound/releases/暮边镇-1.1.2.apk`。APK 不提交到 Git 源码仓库；当前没有 GitHub Release 下载附件，可使用交付文件或自行构建。

使用本地开发证书签名，后续覆盖升级需保留同一证书。卸载前请导出剧情存档。

## 操作与旅程

| 动作 | 手机 | 键盘 |
| --- | --- | --- |
| 移动 | 左下摇杆 | WASD / 方向键 |
| 三段连击 | 点击或按住攻击 | J / Space |
| 闪避 | 闪避按钮 | K |
| 格挡 / 完美格挡 | 按住格挡 / 迎击瞬间按下 | L |
| 喝药 | 药剂按钮 | H |
| 交谈 / 调查 | 靠近后点击交互 | E |
| 暂停 | 暂停按钮 | Esc |

首次旅程：与伊妲交谈，向格伦完成实操训练，再找洛恩接任务，从东门进入原野。小镇地图可以快速导航；旅店可休息补给。

攻击、闪避和格挡消耗体力；连续动作后需要留出恢复时间。红色破盾预警要闪避，不能靠格挡硬接。训练要求三连、两次闪避、普通格挡和完美格挡。设置中可调整音量、震屏、30/60 FPS 和援助模式。

## 存档升级

活跃剧情使用原来的 `duskbound.save.v1`。1.0.x 的剧情、财产与结局，以及在 1.1.0 中继续过的序章进度，都从该存档继续，不重新初始化或回退。

1.1.0 的训练庭存档及迁移备份原样保留，不再作为另一套可玩流程。只有训练记录、没有剧情存档时，选择「开始新旅程」进入第一章。训练不产生永久财产，不能换算为剧情奖励。

自动保存、有效旧备份与损坏提示沿用现有逻辑。当前存档导入导出用于剧情存档；原始训练记录不自动覆盖剧情档。

## 本地运行与构建

项目采用 JavaScript Canvas + Java Android 宿主。使用 Node.js 22 或更新版本、pnpm，在仓库根目录运行：

```powershell
cd Duskbound
pnpm install --frozen-lockfile
node tools/build.mjs
node tools/serve.mjs
```

浏览器打开 [本地预览](http://localhost:4173/)。Windows PowerShell 7 下构建 APK：

```powershell
./android/install-toolchain.ps1
./android/build.ps1
```

构建使用 JDK 17、Android SDK Platform 35 与 Build Tools 35；工具链在仓库根 `.tooling/`。签名密钥不上传。详见 [Android 构建说明](Duskbound/android/README.md)。

```powershell
node --test tests/*.test.js
node tests/ui-smoke.mjs
node tests/unified-entry-smoke.mjs
./android/test-save-codec.ps1
```

浏览器测试需 Playwright 与 Edge；可通过脚本支持的 `PLAYWRIGHT_MODULE`、`BROWSER_PATH` 指定本机环境。`v2-ui-smoke.mjs` 已标记为停用样板的历史检查，不计入当前版本通过数。
