# 暮边镇：七灯余响

**当前版本：1.1.0 · 手感样板**

暮边镇是一款可离线游玩的安卓横屏动作 RPG。七口钟响了八次，巡界者提灯出发，寻找多出来的那一道回声。

1.1.0 开始落实[第二版完整设定](暮边镇_第二版_七灯余响_完整设定.md)，先交付可实际操作的战斗样板：一处训练庭、四种武器、一名守灯人和三类敌人。第二版的完整三地区、四职业、24 武器与续章故事仍在后续制作范围内。

## 1.1.0 更新内容

- **俯视自由走位**：二维移动，可边走边射击；左右手触控分别控制移动和攻击。
- **辅助与手动瞄准**：自动选择射程内、无遮挡的目标；拖动攻击键切换手动瞄准。
- **四种武器**：驿站手枪、破门散弹、巡界短剑、线灯杖。两把随身切换，各自保留冷却，共享能量。手枪与短剑不消耗能量。
- **新的防御节奏**：生命与护盾分开；停止受伤四秒后回盾。闪步有两次储量并逐次恢复，守灯人的灯环提供减伤与普通敌弹清除。
- **训练与两波试炼**：四种运动靶、实体掩体、雾噬鼠、裂爪犬和空壳弩手；敌人有出生及攻击预警，并能绕掩体寻路。
- **碰撞与伤害规则**：高速弹体检查经过的路径；墙体遮挡生效；同一散弹包对同一敌人最多结算一次；短剑仅在有效帧清除前方普通弹。
- **保存与恢复**：设置、键位重绑、导入导出、房内快照、后台暂停；奖励与领取标记一起保存，避免读档重复领铜筹。
- **保留旧版内容**：首页「回看序章」可继续游玩余烬初巡的小镇、训练、七房远征、首领及两个结局。

目前画面采用程序绘制占位素材。正式角色图集、表情和场景资源的制作要求见[美术清单](Duskbound/ART-V2-PRODUCTION.md)。

## 安卓安装

最低 Android 8.0，横屏运行，使用系统 Android System WebView。安装后无需联网、账号或服务器。

1. 将交付的 `暮边镇-1.1.0.apk` 传到手机。
2. 在文件管理器中打开，按系统提示允许当前来源安装应用。
3. 已安装同签名 1.0.x 的手机可直接覆盖安装，保留本机数据。
4. 打开「暮边镇」，确认首页显示 `v1.1.0`，点击「进入训练庭」。

本地构建产物位于 `Duskbound/releases/暮边镇-1.1.0.apk`。APK 未提交到 Git 源码仓库，本版尚未发布 GitHub Release 下载附件；可以使用已交付安装包，或按下方步骤自行构建。

本版使用本地开发证书签名。后续覆盖安装需要保持同一证书；卸载前请分别导出需要保留的新旧两个存档。

## 操作与首次试玩

| 动作 | 手机 | 默认键鼠 |
| --- | --- | --- |
| 移动 | 左下摇杆 | WASD |
| 攻击 | 点击一发、按住连发 | 鼠标左键 |
| 手动瞄准 | 拖动攻击键 | 在场景中移动鼠标 |
| 闪步 | 闪步按钮 | Space |
| 灯环 | 灯环按钮 | Q |
| 切换武器 | 切枪按钮 | E |
| 军械台 | 军械台按钮 | F |
| 暂停、喝药、设置、存档 | 暂停菜单 | Esc |

先在军械台分别试用四把武器，练习走射、拖瞄、切枪和短剑清弹，再点击「试炼」挑战两波敌人。键位可在设置中修改。序章沿用原操作，详见[项目说明](Duskbound/README.md#序章操作)。

训练与试炼不发永久财产，铜筹只属于本次试炼。若能量耗尽且两把武器均需能量，可在暂停菜单换取免费应急手枪。重开会重置本次试炼资源；继续游戏则恢复保存的房内状态。

## 旧档升级

首次进入新版会先备份旧档原始数据，再迁移到独立的新存档。旧结局、任务记录和已结算财产保留；旧剑强化转为修复纪念与等值灰铁，超出新上限的药剂存入镇仓。旧版途中进度迁移到安全训练庭。

原始旧档保持可用于序章。迁移完成后，新旧存档独立推进；源档损坏或无法完成备份时会提示问题并阻止自动覆盖。具体字段与恢复边界见[存档说明](Duskbound/V2-STATUS.md#存档边界)。

## 本地预览与构建

项目采用 **JavaScript Canvas + Java Android 宿主**。以下命令从仓库根目录开始，使用 Node.js 22 或更新版本及 pnpm：

```powershell
cd Duskbound
pnpm install --frozen-lockfile
node tools/build.mjs
node tools/serve.mjs
```

浏览器打开 [本地预览](http://localhost:4173/)。同一局域网的手机可访问电脑的局域网 IP 与 4173 端口。离线安装交付使用 APK。

Windows PowerShell 7 下构建安卓包：

```powershell
./android/install-toolchain.ps1
./android/build.ps1
```

构建使用 JDK 17、Android SDK Platform 35 和 Build Tools 35，输出 APK、SHA-256 与签名验证报告。工具链默认安装到仓库根目录 `.tooling/`。签名密钥不要提交到仓库。完整说明见 [Android 构建文档](Duskbound/android/README.md)。

逻辑与原生传输检查：

```powershell
node --test tests/*.test.js
node tests/v2-playthrough.mjs
./android/test-save-codec.ps1
```

浏览器检查脚本位于 `Duskbound/tests/`，使用 Playwright 与 Edge；其他环境需按脚本设置 `PLAYWRIGHT_MODULE`、`BROWSER_PATH`。测试报告生成到 `tests/output/`。
